# Zuvan Software Services Pvt. Ltd. (Zuvan Softsol)

Modern, fast, and responsive corporate web application built with **Next.js 14 (App Router)**, **TypeScript**, and **Tailwind CSS**.

> **"Technology. Talent. Tomorrow."**  
> Practical, client-focused IT consulting, specialized staffing and executive recruitment across India.

---

## 🚀 Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Server Components & Client Components)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom brand palettes, fluid typography, and glassmorphic designs
- **Language**: TypeScript
- **Icons**: [Lucide React](https://lucide.dev/)
- **Fonts**: Next.js Google Fonts (`Inter` & `Plus Jakarta Sans`)

---

| Route | Description |

## 🛠️ Getting Started

### Prerequisites

Ensure [Node.js](https://nodejs.org/) (v18.17+ or v20+) and `npm` are installed.

### Development Server

Run the local development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the website.

### Production Build

To build the project for production:

```bash
npm run build
```

To start the production server:

```bash
npm start
```
